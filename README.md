# br-validators

Validação e formatação de documentos brasileiros para PHP, sem dependências em runtime.

> **Em desenvolvimento.** A API ainda não foi publicada; veja o [PRD](PRD.md) para o escopo da v0.1.

## Requisitos

- PHP 8.2 ou superior

## Instalação

```bash
composer require caiolucas/br-validators
```

## Desenvolvimento

```bash
composer install
composer test      # PHPUnit
composer analyse   # PHPStan (level max)
composer check     # ambos
```
